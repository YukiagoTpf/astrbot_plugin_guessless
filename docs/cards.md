# 卡片（`grid.py`）

出题和每次提示只发一张 1080×1080 的图：

- 中间 16:9（1080×608）是图区。
- 上下黑边写题型、进度、剩余时间和已给出的提示。提示按固定格位排：上面 2 行、下面 3 行，每行两条，太长的截断。
- 答对或超时发一段文字加一张答案卡：图区整图公开，标题写答案，右上角写原名。

## 九宫格（游戏、动画、宝可梦）

- 原图居中裁切成 16:9，不拉伸，分成 3×3 格，每次提示揭开一格。
- 宝可梦的官方立绘是透明底，不裁：整张缩进图区正中的正方形（浅色底），九宫格只画在这个正方形上；几乎空白的格子最后才揭开。

## 街景（地点、日本地点）

不画九宫格，三张图一次全给：左边一张大图，右边上下两张小图。「提示」只加文字线索。

## 轮廓（国家）

不画九宫格，「提示」只加文字线索。

- 题目国家的剪影居中，四周各留出它自身尺寸 35% 的范围（`grid.MAP_PAD`），再按图区比例补齐。
- 范围内的邻国画成灰色，国与国之间留一道深色缝；画面里出现的题目国家属地（阿拉斯加、科西嘉）也画成剪影色。
- 国界的画法：先在灰度图上按国家编号填色（大国先画、内洞填回海，被包住的国家后画，所以莱索托、圣马力诺不会被盖掉），编号变化的地方就是国界和海岸线。归在同一组的要素编号相同，中间不会出现边界线。
- 按中心纬度压缩经度，近似等积，高纬国家不变胖；跨 180° 经线的（俄罗斯、斐济）把另一侧挪过来接上。
- 2 倍大小画再缩小，边缘平滑。
