# 玩法

## 指令

| 群里发 | 作用 |
|---|---|
| `@机器人 猜游戏` / `猜动画` / `猜宝可梦` | 开题：揭开 1 格 + 1 条提示 |
| `@机器人 猜地点`（也可以说 `猜街景`） | 三张街景（同一位置的三个方向）一次全给，猜是哪个国家 |
| `@机器人 猜日本地点`（也可以说 `猜日本街景`） | 同上，街景只在日本，猜都道府县 |
| `@机器人 猜国家` | 国家剪影居中、周围一圈邻国画成灰色，猜是哪个国家 |
| `提示` | 不用 @。九宫格题再揭开 1 格 + 1 条提示；街景和轮廓题只加 1 条文字线索 |
| 直接说答案 | 不用 @。猜错不回复，猜对公布答案并记 1 次 |
| `@机器人 游戏排行榜` / `动画排行榜` / `宝可梦排行榜` / `地点排行榜` / `国家排行榜` / `日本地点排行榜` | 本群这一类答对次数前 10 |
| `@机器人 增加 N 题` | 仅管理员：本群额外放开 N 道题（N 为 1–100 的阿拉伯数字，也可以说「加 N 题」「增加 N 道题」） |
| `@机器人 暂停` / `@机器人 重新开始` | 仅管理员：暂停本群猜题（进行中的题作废并公布答案），重启后仍保持，直到重新开始 |

「管理员」指 AstrBot 配置里 `admins_id` 列出的账号。私聊发开题指令会被打发回群里。

## 一道题的流程

- 每个群同时只有一道题，进行中再开会回「还有一道在进行」和剩余时间。
- 限时 2 分钟（`round_seconds`），时间到公布答案。答对或超时都会发一张答案卡（整图公开、标题写答案）。
- `提示` 有 5 秒冷却（`hint_cooldown_seconds`），防止几个人同时喊一下揭开好几格；冷却中喊，每个冷却窗口只回一次「等 N 秒」。
- 九格全开、线索给完后再喊提示，只回剩余时间。
- 答对的文案按用了几格 / 几条线索分三档：≤ 2、3–6、≥ 7。

## 额度

- 每个群每小时最多开 10 道题（`hourly_limit`，0 为不限），所有题型共用，按最近一小时滚动计。超了回「N 分钟后再来」。
- 题没出成（图片下载失败等）不扣额度。
- 管理员「增加 N 题」放开的题数单独记，每小时额度用完后才扣，不过期。
- 额度存在磁盘上，重启不清零。

## 重启时进行中的题

进行中的题只在内存里，重启 AstrBot 后不会接着猜。插件会把每道进行中的题另存一份；下次启动时退回这道题扣的额度，等平台连上后在群里公布答案（最多等 3 分钟）。

## 判定规则（`core/answer.py`）

全半角、繁简（`zhconv`）、大小写、空格和标点都忽略，对中文名、原名和各来源的译名、别名逐个比，满足任意一条就算对：

- 完全一致；
- 说出标题中连续的一大段（≥ 3 字且 ≥ 标题的 40%，标题 ≥ 5 字时才允许），如「旷野之息」「上低音号」；
- 主副标题之间有分隔符时，只说主标题也算，如「荒野大镖客2」；
- 句子里包含完整标题（标题 ≥ 4 字），如「是不是极乐迪斯科」。

猜日本地点时「东京」「大阪」这样省掉都府县也算。国名认 Wikidata 的中英文名和别名，但去掉单字和两个字母的代码，免得「美」「US」这种随口一说就算对。
