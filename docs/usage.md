# 玩法

## 指令

| 群里发 | 作用 |
|---|---|
| `@机器人 猜游戏` / `猜动画` / `猜宝可梦` | 开题：揭开 1 格 + 1 条提示 |
| `@机器人 听歌猜番` | 一张卡片加一条语音：动画 OP / ED 开头 2 秒，猜是哪部番 |
| `@机器人 盲猜宝可梦` | 不给图，一只宝可梦一只宝可梦地猜，每猜一只回一张对比表 |
| `@机器人 猜萝卜` | 九宫格，机体设定图，猜是哪台机体（高达和超级机器人大战里的） |
| `@机器人 盲猜萝卜` | 不给图，一台一台地猜高达机体，每猜一台回一张对比表 |
| `@机器人 猜Vtuber`（也可以说 `猜V`） | 九宫格，B 站头像，猜是哪位虚拟主播（国内外都有） |
| `@机器人 猜群友` | 群友头像切成 5×5，只露 1 格，越给越大，猜是谁 |
| `@机器人 猜地点`（也可以说 `猜街景`） | 三张街景（同一位置的三个方向）一次全给，猜是哪个国家 |
| `@机器人 猜日本地点`（也可以说 `猜日本街景`） | 同上，街景只在日本，猜都道府县 |
| `@机器人 盲猜地点` | 不给图，一个国家一个国家地猜，每猜一个回一张对比表 |
| `@机器人 猜国家` | 暂时下线，只回「好危险，不踩啦」（排行榜同样） |
| `提示` | 不用 @。九宫格题再揭开 1 格 + 1 条提示；听歌猜番放更长的一段（2、4、7、12、20 秒，都从头放）+ 1 条提示；猜群友换一块更大的；街景、盲猜只加 1 条文字线索 |
| 直接说答案 | 不用 @。每人每题最多猜 5 次（盲猜萝卜 10 次），见下文「猜的次数和距离」。猜对公布答案并记 1 次 |
| `@机器人 游戏排行榜` / `动画排行榜` / `听歌猜番排行榜` / `宝可梦排行榜` / `盲猜宝可梦排行榜` / `萝卜排行榜` / `盲猜萝卜排行榜` / `Vtuber排行榜` / `群友排行榜` / `地点排行榜` / `盲猜地点排行榜` / `日本地点排行榜` | 本群这一类答对次数前 10 |
| `@机器人 排行榜`（也可以说 `战斗力榜`、`总排行榜`） | 仅管理员：马上发一张各题型的排行榜图，和整点播报的一样，见下文「整点排行榜」 |
| `@机器人 增加 N 题` | 仅管理员：本群额外放开 N 道题（N 为 1–100 的阿拉伯数字，也可以说「加 N 题」「增加 N 道题」） |
| `@机器人 暂停` / `@机器人 重新开始` | 仅管理员：暂停本群猜题（进行中的题作废并公布答案），重启后仍保持，直到重新开始 |

「管理员」指 AstrBot 配置里 `admins_id` 列出的账号。私聊发开题指令会被打发回群里。

@机器人 说了「猜xx」「盲猜xx」「听歌猜xx」但没有这个玩法（比如「猜歌手」），回一句「哪来的功能」；不 @ 的不理，暂停中的群也不理。

## 整点排行榜

玩过的群每到整点（`board_interval_hours`，默认每小时，0 关闭）收到一张图：各题型答对次数前 5 名，名字后面用黄字标出上次播报以来新答对了几次。这段时间没人答对就不发；正在出题时等这道题结束再发。播报需要知道往哪个群发，所以插件更新后要等群里有人说过话才会开始播。

管理员 @机器人 发「排行榜」可以提前发一张，标题写当时的时间；这次也算一次播报，下次整点的「新增」从这次算起，这期间没人答对整点就不再发。

## 一道题的流程

- 每个群同时只有一道题，进行中再开会回「还有一道在进行」和剩余时间。
- 限时 2 分钟（`round_seconds`），盲猜宝可梦、盲猜萝卜、盲猜地点 5 分钟（`blind_round_seconds`），时间到公布答案。答对或超时都会发一张答案卡（整图公开、标题写答案）。
- `提示` 有 5 秒冷却（`hint_cooldown_seconds`），防止几个人同时喊一下揭开好几格；冷却中喊，每个冷却窗口只回一次「等 N 秒」。
- 九格全开、线索给完后再喊提示，只回剩余时间。
- 答对的文案按用了几格 / 几条线索分三档：≤ 2、3–6、≥ 7。

## 猜的次数和距离

- 每人每题最多猜 5 次（`max_guesses`），盲猜萝卜 10 次（`mechadle_max_guesses`），0 为不限。用完后说什么都不算，包括说对；用完的那次回一句提醒。
- 只有说出「某个答案」才算一次，闲聊不算：
  - 游戏、动画、宝可梦、盲猜宝可梦、猜萝卜、盲猜萝卜、猜Vtuber：说的是题库里任意一道题的答案（判法同下文「判定规则」）。说了题库外的作品也不算，反正不可能对；
  - 猜群友：@ 了群里的某人，或者说了某人的 QQ 号、群名片、昵称（见下文「猜群友」）；
  - 听歌猜番：说的是猜动画题库里的任意一部；
  - 地点、国家、日本地点、盲猜地点：说的是任意一个可猜的国家 / 都道府县，没街景、不出题的国家也算。`geo.EXCLUDE` 里的地区说了不回、不算。
- 自己重复猜同一个不算。
- 游戏、动画、宝可梦、听歌猜番、猜萝卜、猜Vtuber、猜群友猜错不回复；盲猜猜错回对比表，见下文；地点、国家、日本地点猜错回距离和还剩几次：
  - 猜地点、猜日本地点：你猜的国家 / 都道府县离拍摄地最近的城镇（GeoNames 人口 1.5 万以上）有多远。不用中心，是因为猜俄罗斯时离北海道的拍摄地会有六千多公里，跟直觉对不上；
  - 猜国家：两国本土轮廓的面积中心之间（`geo.centroid`），所以邻国也有几百公里；
  - 100 公里以上只给两位有效数字；
  - 猜国家还附一张世界地图：本题猜过的国家按离答案的远近上色（越近越红），图下按距离从近到远列出来，左下角是题目的剪影；
  - 本题有人猜过的地方再猜，回上次的距离，不扣次数。

## 盲猜宝可梦

不给图，说一只宝可梦，回一张表，把它和答案逐项比：

| 列 | 绿 | 黄 | 红 |
|---|---|---|---|
| 世代、进化阶段 | 一样 | 世代差 1 | 不一样，箭头指答案更大（↑）还是更小（↓） |
| 属性 1、属性 2 | 这一格一样 | 答案有这个属性，但在另一格 | 答案没有这个属性 |
| 颜色 | 一样 | | 不一样 |
| 种族值 | 一样 | 差 40 以内 | 差得更多；都带箭头 |

表里新猜的在上面，最多列 9 只。开题时没有线索，「提示」依次给分类、进化关系、首字。答对按全群一共猜了几次分档：≤ 3 次、4–9 次、≥ 10 次。

## 盲猜萝卜

同盲猜宝可梦，只出 Gundam Wiki 上有资料的高达机体（超级机器人大战里其他作品的机体没有成体系的资料，只在猜萝卜里出）。每人能猜 10 次；表的右边放着设定图九宫格里随机的一格（有内容的），整道题不变、不会揭开：

| 列 | 绿 | 黄 | 红 | 灰 |
|---|---|---|---|---|
| 世界观（宇宙世纪、C.E.、西历……） | 一样 | | 不一样 | |
| 登场年份 | 一样 | 差 3 年以内 | 不一样，带箭头 | |
| 阵营、机型（试作 / 量产 / 少量生产 / 专用）、机械设计 | 一样 | | 不一样 | 猜的这台没有资料 |
| 型号开头（RX、MS、GN……） | 一样 | | 不一样 | 没有型号 |

「提示」依次给出自哪部作品、全高、首字。

## 盲猜地点

同盲猜宝可梦，猜国家，能猜的国家同猜地点。每列都是能排除一大片的资料；货币、美食、名胜在表里比不出来，放进「提示」：

| 列 | 绿 | 黄 | 红 |
|---|---|---|---|
| 地区（东亚、东南亚、西欧、中欧、南部非洲、加勒比、太平洋岛国……） | 同一地区 | 同一大洲 | 不同大洲 |
| 方位：答案离你猜的国家多远、在哪个方向 | | 接壤，或者最近的城镇相距 1000 公里以内 | 更远 |
| 人口、面积 | 一样 | 差不到一半（大的不到小的 1.5 倍） | 差得更多；都带箭头 |
| 语言（你猜的国家的第一语言） | 和答案的一样 | 答案的前三种语言里有它，或者你猜的国家也说答案的第一语言 | 都不沾边 |
| 行驶方向 | 一样 | | 不一样 |

- 地区按国内地理课本的分法：欧洲分北欧、西欧、中欧、南欧、东欧（波罗的海三国算东欧），伊朗、阿富汗算西亚，墨西哥算北美。
- 方位：接壤的写「接壤」，其余写两国最近的城镇（GeoNames 人口 1.5 万以上）相距多远，规则同猜地点报距离。箭头是从你猜的国家的人口重心看答案的人口重心，按太平洋居中的世界地图画直线，从美国看日本是往左。
- 「提示」依次给货币、美食、名胜、首字。货币只给单位（「印度卢比」给「卢比」），只剩一个字的（日元、美元）和用国名首字的（泰铢）不给。
- 人口过千万或面积过 50 万平方公里的是大众题，其余是小众题（`niche_ratio`）。
- 答案卡是对比表，最上面加一行答案自己的资料。

## 猜萝卜

- 机体名互相包含的很多（「自由高达」和「强袭自由高达」），所以和地点类一样先认说的是哪台：完全说中某台机体名字的优先，说「自由高达」不会因为是「强袭自由高达」的一大段被算对。
- 认中文名、各地译名和外号（老虎 / 古夫、牛高达、新安洲 / 新安州……）、日文名、英文名和型号（RX-78-2 说成 RX782 也行）。

## 猜Vtuber

- 题目是 vtbs.moe 名单里 B 站粉丝最多的虚拟主播，国内（主要说中文的）和国外（日语、英语等）大约二比一，图是 B 站头像。
- 提示依次给：主要语言、所属团体、B 站粉丝数、大航海人数、同团的另外两位、首字。没有团体或没人上舰的跳过这条。
- 只认完整说出的名字：中文名、日文名、英文名、B 站昵称，以及去掉 Official、_Channel 这类后缀的（「東雪蓮Official」说「东雪莲」）；「七海Nana7mi」这种中文加英文的，两半都算。B 站昵称常带日常用语（「嘉然今天吃什么」），说出一段就算的话会误伤闲聊，所以不按一大段算对。

## 猜群友

- 开题时现拉群成员，随机挑一位：开题的人和机器人自己不出；30 天内说过话的优先（这样的人不到 8 个才从全体里挑）；同一轮里出过的先不出，都出过了再重来。默认头像、几乎纯色的头像跳过，连着 12 个都不行就不出，回「没挑到能猜的头像」。
- 头像切成格子，分四段：5×5 露 1 格 → 5×5 露 2 格 → 4×4 露 1 格 → 3×3 露 1 格。露哪格开题时就定好，只露看得出东西的格子（不露纯色背景）。喊「提示」进下一段。卡片上另有一条线索：入群时间。
- 怎么猜：@TA、说 TA 的 QQ 号、群名片或昵称，或者名片 / 昵称里只属于 TA 一个人的一段（至少 2 个字，且不少于名字的四成，免得「可以」「什么」也算猜了人）。成员名单是开题那一刻的快照，局中改名片不算。
- 被猜的那位群友自己说什么都不算。
- 答对按到第几段分档：第 1 段、第 2–3 段、第 4 段。
- 头像只在出题时现拉、只在内存里出图，不存盘；答案只公布群名片（没有就用昵称），不公布 QQ 号。

## 听歌猜番

- 题目是猜动画题库里在 [AnimeThemes](https://animethemes.moe) 有 OP / ED 的作品，每次随机一首，OP 的概率是 ED 的两倍。
- 每段都从歌的开头放（去掉开头的静音），喊「提示」放更长的一段，同时卡片上多一条提示：先是 OP / ED，然后和猜动画一样是放送时间、改编自、标签、动画制作。
- 答案卡是这部番的截图，最上面写歌名和歌手。
- 答对按听到第几段分档：第 1 段、第 2–4 段、第 5 段。

## 额度

- 每个群每小时最多开 10 道题（`hourly_limit`，0 为不限；个别群可以在 `group_hourly_limits` 里单独设），所有题型共用，按最近一小时滚动计。超了回「N 分钟后再来」。
- 题没出成（图片下载失败等）不扣额度。
- 设了宵禁的群（`group_curfews`），宵禁时段里开题回「几点之后再来」；宵禁开始前已经开出的题照常答完，排行榜照常能看。
- 管理员「增加 N 题」放开的题数单独记，每小时额度用完后才扣，不过期。
- 额度存在磁盘上，重启不清零。

## 重启时进行中的题

进行中的题只在内存里，重启 AstrBot 后不会接着猜。插件会把每道进行中的题另存一份；下次启动时退回这道题扣的额度，等平台连上后在群里公布答案（最多等 3 分钟）。

## 判定规则（`core/answer.py`）

全半角、繁简（`zhconv`）、大小写、空格和标点都忽略，对中文名、原名和各来源的译名、别名逐个比，满足任意一条就算对：

- 完全一致；
- 说出标题中连续的一大段（≥ 3 字且 ≥ 标题的 40%，标题 ≥ 5 字时才允许），如「旷野之息」「上低音号」；
- 主副标题之间有分隔符时，只说主标题也算，如「荒野大镖客2」；
- 句子里包含完整标题（标题 ≥ 4 字），如「是不是极乐迪斯科」。

地点、国家、日本地点、盲猜地点先认说的是哪个地方，完全说中某个地名的优先：「几内亚」是几内亚，不会因为是「赤道几内亚」的一大段被算对。猜萝卜同理；猜Vtuber只认完全说中的，见上文。

猜日本地点时「东京」「大阪」这样省掉都府县也算。国名认 Wikidata 的中英文名和别名，但去掉单字和两个字母的代码，免得「美」「US」这种随口一说就算对。
