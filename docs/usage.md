# 玩法

## 指令

| 群里发 | 作用 |
|---|---|
| `@机器人 猜游戏` / `猜动画` / `猜宝可梦` | 开题：揭开 1 格 + 1 条提示 |
| `@机器人 听歌猜番` | 一张卡片加一条语音：动画 OP / ED 开头 2 秒，猜是哪部番 |
| `@机器人 盲猜宝可梦` | 不给图，一只宝可梦一只宝可梦地猜，每猜一只回一张对比表 |
| `@机器人 猜萝卜` | 九宫格，机体设定图，猜是哪台机体（高达和超级机器人大战里的） |
| `@机器人 盲猜萝卜` | 不给图，一台一台地猜高达机体，每猜一台回一张对比表 |
| `@机器人 猜地点`（也可以说 `猜街景`） | 三张街景（同一位置的三个方向）一次全给，猜是哪个国家 |
| `@机器人 猜日本地点`（也可以说 `猜日本街景`） | 同上，街景只在日本，猜都道府县 |
| `@机器人 猜国家` | 国家剪影居中，猜是哪个国家（答案卡上再画出周围的邻国） |
| `提示` | 不用 @。九宫格题再揭开 1 格 + 1 条提示；听歌猜番放更长的一段（2、4、7、12、20 秒，都从头放）+ 1 条提示；街景、轮廓、盲猜只加 1 条文字线索 |
| 直接说答案 | 不用 @。每人每题最多猜 5 次，见下文「猜的次数和距离」。猜对公布答案并记 1 次 |
| `@机器人 游戏排行榜` / `动画排行榜` / `听歌猜番排行榜` / `宝可梦排行榜` / `盲猜宝可梦排行榜` / `萝卜排行榜` / `盲猜萝卜排行榜` / `地点排行榜` / `国家排行榜` / `日本地点排行榜` | 本群这一类答对次数前 10 |
| `@机器人 增加 N 题` | 仅管理员：本群额外放开 N 道题（N 为 1–100 的阿拉伯数字，也可以说「加 N 题」「增加 N 道题」） |
| `@机器人 暂停` / `@机器人 重新开始` | 仅管理员：暂停本群猜题（进行中的题作废并公布答案），重启后仍保持，直到重新开始 |

「管理员」指 AstrBot 配置里 `admins_id` 列出的账号。私聊发开题指令会被打发回群里。

## 一道题的流程

- 每个群同时只有一道题，进行中再开会回「还有一道在进行」和剩余时间。
- 限时 2 分钟（`round_seconds`），盲猜宝可梦、盲猜萝卜 5 分钟（`blind_round_seconds`），时间到公布答案。答对或超时都会发一张答案卡（整图公开、标题写答案）。
- `提示` 有 5 秒冷却（`hint_cooldown_seconds`），防止几个人同时喊一下揭开好几格；冷却中喊，每个冷却窗口只回一次「等 N 秒」。
- 九格全开、线索给完后再喊提示，只回剩余时间。
- 答对的文案按用了几格 / 几条线索分三档：≤ 2、3–6、≥ 7。

## 猜的次数和距离

- 每人每题最多猜 5 次（`max_guesses`，0 为不限）。用完后说什么都不算，包括说对；用完的那次回一句提醒。
- 只有说出「某个答案」才算一次，闲聊不算：
  - 游戏、动画、宝可梦、盲猜宝可梦、猜萝卜、盲猜萝卜：说的是题库里任意一道题的答案（判法同下文「判定规则」）。说了题库外的作品也不算，反正不可能对；
  - 听歌猜番：说的是猜动画题库里的任意一部；
  - 地点、国家、日本地点：说的是任意一个可猜的国家 / 都道府县，没街景、不出题的国家也算。`geo.EXCLUDE` 里的地区说了不回、不算。
- 自己重复猜同一个不算。
- 游戏、动画、宝可梦、听歌猜番、猜萝卜猜错不回复；两种盲猜猜错回对比表，见下文；地点、国家、日本地点猜错回距离和还剩几次：
  - 猜地点、猜日本地点：你猜的国家 / 都道府县离拍摄地最近的城镇（GeoNames 人口 1.5 万以上）有多远。不用中心，是因为猜俄罗斯时离北海道的拍摄地会有六千多公里，跟直觉对不上；
  - 猜国家：两国本土轮廓的面积中心之间（`geo.centroid`），所以邻国也有几百公里；
  - 100 公里以上只给两位有效数字；
  - 猜国家还附一张世界地图：本题猜过的国家按离答案的远近上色（越近越红），图下按距离从近到远列出来，左下角是题目的剪影；
  - 本题有人猜过的地方再猜，回上次的距离，不扣次数。

## 盲猜宝可梦

不给图，说一只宝可梦，回一张表，把它和答案逐项比：

| 列 | 绿 | 黄 | 红 |
|---|---|---|---|
| 世代、进化阶段 | 一样 | 世代差 1 | 不一样，箭头指答案更大（↑）还是更小（↓） |
| 属性 1、属性 2 | 这一格一样 | 答案有这个属性，但在另一格 | 答案没有这个属性 |
| 颜色 | 一样 | | 不一样 |
| 种族值 | 一样 | 差 40 以内 | 差得更多；都带箭头 |

表里新猜的在上面，最多列 9 只。开题时没有线索，「提示」依次给分类、进化关系、首字。答对按全群一共猜了几次分档：≤ 3 次、4–9 次、≥ 10 次。

## 盲猜萝卜

同盲猜宝可梦，只出 Gundam Wiki 上有资料的高达机体（超级机器人大战里其他作品的机体没有成体系的资料，只在猜萝卜里出）：

| 列 | 绿 | 黄 | 红 | 灰 |
|---|---|---|---|---|
| 世界观（宇宙世纪、C.E.、西历……） | 一样 | | 不一样 | |
| 登场年份 | 一样 | 差 3 年以内 | 不一样，带箭头 | |
| 阵营、机型（试作 / 量产 / 少量生产 / 专用）、机械设计 | 一样 | | 不一样 | 猜的这台没有资料 |
| 型号开头（RX、MS、GN……） | 一样 | | 不一样 | 没有型号 |

「提示」依次给出自哪部作品、全高、首字。

## 猜萝卜

- 机体名互相包含的很多（「自由高达」和「强袭自由高达」），所以和地点类一样先认说的是哪台：完全说中某台机体名字的优先，说「自由高达」不会因为是「强袭自由高达」的一大段被算对。
- 认中文名、各地译名和外号（老虎 / 古夫、牛高达、新安洲 / 新安州……）、日文名、英文名和型号（RX-78-2 说成 RX782 也行）。

## 听歌猜番

- 题目是猜动画题库里在 [AnimeThemes](https://animethemes.moe) 有 OP / ED 的作品，每次随机一首，OP 的概率是 ED 的两倍。
- 每段都从歌的开头放（去掉开头的静音），喊「提示」放更长的一段，同时卡片上多一条提示：先是 OP / ED，然后和猜动画一样是放送时间、改编自、标签、动画制作。
- 答案卡是这部番的截图，最上面写歌名和歌手。
- 答对按听到第几段分档：第 1 段、第 2–4 段、第 5 段。

## 额度

- 每个群每小时最多开 10 道题（`hourly_limit`，0 为不限），所有题型共用，按最近一小时滚动计。超了回「N 分钟后再来」。
- 题没出成（图片下载失败等）不扣额度。
- 管理员「增加 N 题」放开的题数单独记，每小时额度用完后才扣，不过期。
- 额度存在磁盘上，重启不清零。

## 重启时进行中的题

进行中的题只在内存里，重启 AstrBot 后不会接着猜。插件会把每道进行中的题另存一份；下次启动时退回这道题扣的额度，等平台连上后在群里公布答案（最多等 3 分钟）。

## 判定规则（`core/answer.py`）

全半角、繁简（`zhconv`）、大小写、空格和标点都忽略，对中文名、原名和各来源的译名、别名逐个比，满足任意一条就算对：

- 完全一致；
- 说出标题中连续的一大段（≥ 3 字且 ≥ 标题的 40%，标题 ≥ 5 字时才允许），如「旷野之息」「上低音号」；
- 主副标题之间有分隔符时，只说主标题也算，如「荒野大镖客2」；
- 句子里包含完整标题（标题 ≥ 4 字），如「是不是极乐迪斯科」。

地点、国家、日本地点先认说的是哪个地方，完全说中某个地名的优先：「几内亚」是几内亚，不会因为是「赤道几内亚」的一大段被算对。

猜日本地点时「东京」「大阪」这样省掉都府县也算。国名认 Wikidata 的中英文名和别名，但去掉单字和两个字母的代码，免得「美」「US」这种随口一说就算对。
