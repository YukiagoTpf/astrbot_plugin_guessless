# Guessless

> 两分钟，零人答对。

[AstrBot](https://github.com/AstrBotDevs/AstrBot) 群聊猜题插件：看图猜游戏、动画、宝可梦、机体（高达和超级机器人大战）、虚拟主播、魔兽世界的地图，看模糊处理的官方头像猜 AV 女优，看配过的四个角色猜日本女声优，听 OP / ED 猜番，按属性对比盲猜宝可梦、高达、国家、日本的市町村、中国的城市、日本酒和魔兽世界的副本首领，看街景猜国家和日本都道府县，看一段 K 线猜之后涨跌几个点，也能答日语文字题、猜英文单词。不需要 LLM。

目前只在 QQ（aiocqhttp / NapCat）上跑过。

## 能猜什么

| 群里发 | 玩法 |
|---|---|
| `@机器人 猜游戏` | 九宫格逐格揭开游戏截图 |
| `@机器人 猜动画` | 九宫格逐格揭开动画截图 |
| `@机器人 听歌猜番` | 听动画 OP / ED 的片段，越听越长 |
| `@机器人 猜宝可梦` | 九宫格逐格揭开官方立绘 |
| `@机器人 盲猜宝可梦` | 不给图，每猜一只就和答案比世代、属性、种族值 |
| `@机器人 猜萝卜` | 九宫格逐格揭开机体设定图（高达和超级机器人大战） |
| `@机器人 盲猜萝卜` | 不给图，每猜一台高达就和答案比世界观、登场年份、阵营 |
| `@机器人 猜Vtuber` | 九宫格逐格揭开 B 站头像，国内外的虚拟主播都有 |
| `@机器人 猜魔兽地图`（也可以只说 `猜魔兽`） | 九宫格逐格揭开魔兽世界的游戏截图，猜是哪张地图（野外地区和主城） |
| `@机器人 猜老师`（也可以说 `猜女优`） | 日本 AV 女优的 FANZA 官方头像（只拍脸）高斯模糊，越给越清楚，猜是谁 |
| `@机器人 猜声优`（也可以说 `猜女声优`、`猜CV`） | 一格格露出日本女声优配过的四个角色（动画角色，有时换一个游戏主役，底下写作品名），作品从冷到热，最后是她最热门作品的主役，猜是谁配的 |
| `@机器人 猜地点` | 同一位置的三张 Google 街景，猜国家 |
| `@机器人 猜日本地点` | 日本的三张街景，猜都道府县 |
| `@机器人 猜地点匹配`（也可以说 `地点连连看`） | 同一片地区两个国家，每国一个地方前后两张街景，打乱排成 2×2，按图号说出各是哪国（「ABBA」）；每人答一次，3 分钟后一起公布，答对的都记分 |
| `@机器人 猜日本地点匹配`（也可以说 `日本连连看`） | 日本同一地方四个都道府县的街景排成 2×2，按图号说出各是哪个县（「BADC」），猜错报对了几个 |
| `@机器人 盲猜地点` | 不给图，每猜一个国家就和答案比地区、方位和距离、人口、面积、语言 |
| `@机器人 盲猜日本地点` | 不给图，猜到市町村（京都、箱根、东京……），比都道府县、方位和距离、人口、面积、级别 |
| `@机器人 盲猜中国地点` | 不给图，猜地级市和省辖县级市（北上广深猜区），比省份、方位和距离、人口、面积、GDP、城市线级 |
| `@机器人 盲猜日本酒` | 不给图，猜日本酒的銘柄（獭祭、十四代……），比产地、方位和距离、人气、华丽 / 浓醇 / 辛口 |
| `@机器人 盲猜魔兽Boss` | 不给图，猜魔兽世界冒险指南里的副本首领（拉格纳罗斯、伊利丹·怒风……），比资料片、副本、类型、第几个、大陆 |
| `@机器人 猜日语`（也可以说 `猜日语语法`、`猜日语单词`） | 日语文字题，填助词、变词形、答词义或读音、选语法表达 |
| `@机器人 猜英文`（也可以说 `猜英文单词`、`猜单词`） | 6174 题，以 ECDICT 的四六级、考研原形词释义为主，另有词形、词性转换、填空及反义近义词，只认完整拼词 |
| `@机器人 英文Wordle`（也可以说 `猜Wordle`、`Wordle`、`wordle`） | 固定五字母，全群默认共用六行棋盘，按绿、黄、灰逐字母推理；提示先词性、后释义 |
| `@机器人 猜成语`（也可以说 `中文Wordle`、`成语Wordle`） | 全群共用四字成语棋盘，按绿、黄、灰逐字推理，默认每人 10 次、全群 10 行；[规则](docs/usage.md#猜成语) |
| `@机器人 猜K线` | A 股、日股、美股（沪深300、日经225、标普500、纳指100）一段藏起名字的日 K，猜之后 20 个交易日涨跌几个点，凑满 5 人按远近排名 |

猜国家（国家剪影）、盲猜以撒道具、猜群友暂时下线，发了只回一句「好危险，不踩啦」。@机器人说了没有的「猜xx」，回「哪来的功能」。

开题后直接说答案，不用 @；喊「提示」多揭开一格或多给一条线索。每人每题最多猜 5 次（盲猜萝卜、盲猜日本 / 中国地点、Wordle 和猜成语 10 次，日本地点匹配、猜日语、猜英文 3 次，猜地点匹配只答一次），猜地点、日本地点猜错会报距离。每题限时 2 分钟（猜地点匹配、日本地点匹配 3 分钟，盲猜和 Wordle 5 分钟，盲猜日本 / 中国地点 7 分钟），每个群每小时最多 10 题（整点刷新，也可以改成滚动刷新、每几分钟一道），可以按群设宵禁，管理员能临时解禁；bot 管理员开题不受宵禁和额度限制。玩过的群每到整点会收到一张各题型排行榜的图（这一小时没人答对就不发），管理员也可以 @机器人 发「排行榜」提前要一张。猜K线不一样：每人说一次涨跌几个点（「涨3」「跌1.5」），凑满 5 人或 3 分钟到点揭晓，离实际最近的拿第一。记不住指令就 @机器人 说「帮助」；说得不准也认（「猜 k 线」「来把盲猜日本」「K线榜」）。完整指令和规则见[玩法](docs/usage.md)。

## 安装

1. AstrBot WebUI → 插件 → 安装插件，填本仓库地址。
2. 可选：在插件配置里填 IGDB 和 Google Maps 的 key，见[配置](docs/configuration.md)。不填也能玩，只是游戏题图退回封面，也不能猜地点。
3. 等后台建好题库（几分钟到一小时不等），就可以在群里开题了。
