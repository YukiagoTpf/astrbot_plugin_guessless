# Guessless

> 两分钟，零人答对。

[AstrBot](https://github.com/AstrBotDevs/AstrBot) 群聊猜题插件：看图猜游戏、动画、宝可梦、机体（高达和超级机器人大战）、虚拟主播，看头像的一小块猜群友，听 OP / ED 猜番，按属性对比盲猜宝可梦、高达、国家和日本的市町村，看街景猜国家和日本都道府县。不需要 LLM。

目前只在 QQ（aiocqhttp / NapCat）上跑过。

## 能猜什么

| 群里发 | 玩法 |
|---|---|
| `@机器人 猜游戏` | 九宫格逐格揭开游戏截图 |
| `@机器人 猜动画` | 九宫格逐格揭开动画截图 |
| `@机器人 听歌猜番` | 听动画 OP / ED 的片段，越听越长 |
| `@机器人 猜宝可梦` | 九宫格逐格揭开官方立绘 |
| `@机器人 盲猜宝可梦` | 不给图，每猜一只就和答案比世代、属性、种族值 |
| `@机器人 猜萝卜` | 九宫格逐格揭开机体设定图（高达和超级机器人大战） |
| `@机器人 盲猜萝卜` | 不给图，每猜一台高达就和答案比世界观、登场年份、阵营 |
| `@机器人 猜Vtuber` | 九宫格逐格揭开 B 站头像，国内外的虚拟主播都有 |
| `@机器人 猜群友` | 只露群友头像的一小块，越给越大，说名片或 @TA |
| `@机器人 猜地点` | 同一位置的三张 Google 街景，猜国家 |
| `@机器人 猜日本地点` | 日本的三张街景，猜都道府县 |
| `@机器人 盲猜地点` | 不给图，每猜一个国家就和答案比地区、方位和距离、人口、面积、语言 |
| `@机器人 盲猜日本地点` | 不给图，猜到市町村（京都、箱根、东京……），比都道府县、方位和距离、人口、面积、级别 |

猜国家（国家剪影）暂时下线，发了只回一句「好危险，不踩啦」。@机器人说了没有的「猜xx」，回「哪来的功能」。

开题后直接说答案，不用 @；喊「提示」多揭开一格或多给一条线索。每人每题最多猜 5 次（盲猜萝卜、盲猜日本地点 10 次），猜地点、日本地点猜错会报距离。每题限时 2 分钟（盲猜 5 分钟，盲猜日本地点 7 分钟），每个群每小时最多 10 题（整点刷新）。玩过的群每到整点会收到一张各题型排行榜的图（这一小时没人答对就不发），管理员也可以 @机器人 发「排行榜」提前要一张。完整指令和规则见[玩法](docs/usage.md)。

## 安装

1. AstrBot WebUI → 插件 → 安装插件，填本仓库地址。
2. 可选：在插件配置里填 IGDB 和 Google Maps 的 key，见[配置](docs/configuration.md)。不填也能玩，只是游戏题图退回封面，也不能猜地点。
3. 等后台建好题库（几分钟到一小时不等），就可以在群里开题了。
