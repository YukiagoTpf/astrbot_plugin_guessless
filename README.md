# Guessless

> 两分钟，零人答对。

[AstrBot](https://github.com/AstrBotDevs/AstrBot) 群聊小游戏插件：九宫格看图猜游戏、动画、宝可梦，看 Google 街景猜国家或日本都道府县，看轮廓猜国家。不需要 LLM。

目前只在 QQ（aiocqhttp / NapCat）上跑过。

## 玩法

| 群里发 | 作用 |
|---|---|
| `@机器人 猜游戏` / `猜动画` / `猜宝可梦` | 开题：揭开 1 格 + 1 条提示，限时 2 分钟；一个群同时只有一道题，进行中再开会回「等一下」 |
| `@机器人 猜地点`（也可以说 `猜街景`） | 三张街景（同一位置的三个方向）一次全给，猜是哪个国家；`提示` 只加文字线索 |
| `@机器人 猜日本地点`（也可以说 `猜日本街景`） | 同上，街景只在日本，猜都道府县；「东京」「大阪」这样省掉都府县也算 |
| `@机器人 猜国家` | 国家轮廓剪影，猜是哪个国家；`提示` 只加文字线索 |
| `提示` | 再揭开 1 格 + 1 条提示（不用 @）；5 秒冷却，冷却中喊会回一次「等 N 秒」 |
| 直接说答案 | 不用 @；猜错不回复，猜对公布答案并记 1 次 |
| `@机器人 游戏排行榜` / `动画排行榜` / `宝可梦排行榜` / `地点排行榜` / `国家排行榜` / `日本地点排行榜` | 本群答对次数前 10 |
| `@机器人 增加 N 题` | 仅 AstrBot 管理员：本群额外放开 N 道题（见下方额度说明） |
| `@机器人 暂停` / `@机器人 重新开始` | 仅 AstrBot 管理员（`admins_id`）：暂停本群猜题（进行中的题作废并公布答案），重启后仍保持，直到重新开始 |

每个群每小时最多开 10 道题（`hourly_limit`），所有猜题共用，按最近一小时滚动计，没出成的题不算；超了回「N 分钟后再来」。管理员发「增加 N 题」（1–100，阿拉伯数字）给本群额外放开 N 道，每小时额度用完后才扣、不过期。

## 安装

AstrBot WebUI → 插件 → 安装插件，填本仓库地址。依赖（`zhconv`、`pyshp`）会自动装。

卡片文字用 Noto Sans CJK（`/usr/share/fonts/opentype/noto`，AstrBot 官方 Docker 镜像自带）；找不到时退回 Pillow 默认字体，中文会显示成方块。

首次启动会在后台建题库：宝可梦、国家几分钟，游戏约 20 分钟，动画约一小时（边建边开放出题）。建好之前开题会回「题库还在搬砖」。

## 配置

WebUI → 插件 → Guessless → 配置。都有默认值，两组 key 是可选的：

| 配置 | 不填会怎样 |
|---|---|
| `igdb_client_id` / `igdb_client_secret` | 游戏题图改用 Metacritic 封面（常印着标题，容易露馅），也没有热度数据，题库只按 MC 分取、不分大众 / 小众。在 [dev.twitch.tv/console](https://dev.twitch.tv/console) 注册应用（OAuth 重定向填 `http://localhost`，类别选 Application Integration）拿到 |
| `google_maps_key` | 不能猜地点、猜日本地点。Google Cloud 建项目、绑结算账号、启用 Street View Static API、建 API 密钥。**街景图片按张计费**（每题 3 张，有每月免费额度），建议把 key 限制为只能调 Street View Static API，并在配额页给每天的请求数设上限 |

其余配置（限时、冷却、题库大小、小众题比例等）见 `_conf_schema.json` 里的说明。

## 卡片（`grid.py`）

出题和提示只发一张 1080 正方形图：中间 16:9 是九宫格（原图居中裁切、不拉伸），上下黑边写题型、进度、剩余时间和已揭开的提示。提示按固定格位排（上 2 行、下 3 行，每行两条），太长的截断。答对或超时发文字 + 答案卡（整图公开，标题写答案）。

- 宝可梦的官方立绘是透明底，不裁：整张缩进图区正中的正方形（浅色底），九宫格只画在正方形上；几乎空白的格子最后才揭开。
- 猜地点、猜日本地点不画九宫格：左边一张大图，右边上下两张小图。
- 猜国家不画九宫格：国家剪影铺满图区（按中心纬度压缩经度，高纬国家不变胖）。

## 文案

所有对群文案都在 `lines.py`，同一场景多条随机抽，想换口吻只改那里。

## 题库

- **动画**：Bangumi 排名前 4000 部里按「看过 + 在看」人数取最热门的 1000 部（TV / 剧场版 / WEB，必须有中文名，排除 NSFW），中文名前缀相同的续作只留最热门的一部。
- **游戏**：候选是 Metacritic ≥ 75 分、媒体评测 ≥ 10 篇的游戏（五千多款），分两档：
  - 大众题：按热度（IGDB 上的评分人数）取前 500 款；
  - 小众题：热度没进大众题的里面，按「MC 分排名 + 热度排名」取前 300 款，高分、又不至于全是没人听过的；
  - 每题 20% 概率出小众题，大约五题一道（`niche_ratio`）。DLC、资料片、合集不出题；有本体的重制 / 加强版 / 移植也不出；Metacritic 把一款游戏拆成两个条目的按 IGDB 去重。
  - 选中的逐个按「英文名 + 年份 ±1」去 Bangumi 搜中文名、别名、开发商。
- **题图**：尽量用不带字的截图，找不到图的作品不进题库（动画按热度往后补）。每道题存多张，每次出题随机挑一张。
  - 动画（免 key）：B 站番剧的分集封面，按中文名搜，Wikidata 有 B 站 ID 的按 ID 认；搜不到就用 AniList 的横幅图（1900×400 裁成 16:9，略糊）。B 站搜得太快会被限流（HTTP 412），所以 3 秒搜一次，被限流就歇 5 分钟；连续 3 次还不行，这次构建剩下的先用横幅，一小时后接着查。
  - 游戏：IGDB 截图，IGDB 上没有再用 Steam 的；没配 IGDB 就用 Metacritic 封面。
- **译名**：Bangumi 的中文名 / 别名之外，再从 Wikidata（简繁、港台、日英的名称和别名）、AniList（罗马音、英文名、别名）、IGDB（别名、地区名）补。游戏在 Bangumi 上没中文名时用 Wikidata 的中文名出题。
- **宝可梦**：PokeAPI（GraphQL，免 key）全国图鉴 1025 只，提示依次是世代、属性、颜色、身高体重、分类、特性、进化、图鉴编号；名字认简繁中、日文、英文，Wikidata 补港译、旧译。第 1–4 世代是大众题、之后是小众题（`pokemon_main_gen`）。
- **地点**（`geo.py`）：在 GeoNames 人口 1.5 万以上城市的城镇中心 1 公里内随机撒点，用街景元数据接口（免费）找附近的 Google 官方全景，离全景最近的城市还在这个国家才算数，每国最多 6 个。出题时现取三张图、不存盘（按张计费，Google 条款也不允许长期缓存）。提示和猜国家一样；国名认 Wikidata 的中英文名和别名。
- **日本地点**：取景规则同上，按都道府县分，每个最多 4 个全景。提示依次是地方（八地方）、特产和名胜各三条（从冷门往有名的给）、县厅所在地首字、县名首字。
- **国家**：Natural Earth 10m 国界，只留本土附近的部分（法国不带海外省、美国不带阿拉斯加和夏威夷）。人口过千万或面积过 50 万平方公里的是大众题。提示依次是半球、大洲、行驶方向、货币、名胜、主要语言、美食、最有名的名胜、国名首字；没收录名胜的国家改给人口、面积、首都首字。`geo.EXCLUDE` 里的地区不出题。
- **特产、名胜、美食**是手写的（`hint_data.py`，每国 / 每县按有名程度排），不带国名、县名、首都名；`bank.scrub` 再兜一层底：Wikidata 来的货币、语言里带国名的部分删掉（「巴西雷亚尔」→「雷亚尔」），删不干净的整条不要。改了 `hint_data.py` 要把 `geo.HINTS_VERSION` 改一下，题库才会重建。
- 每 7 天自动刷新；改了题库大小、填了或删了 key、升级了题目格式，一小时内重建，重建期间旧题库照常出题。key 填错时构建中止并保留旧题库，日志里有「拒绝访问」。
- 数据都在 `data/plugin_data/astrbot_plugin_guessless/`：`bank_*.json` 是题库，其余是各数据源的查询缓存（删掉会在下次重建时重新查）、`images/` 图片缓存、`scores.json` 排行榜、`paused.json` 暂停中的群、`quota.json` / `bonus.json` 开题额度。

## 判定规则（`answer.py`）

全半角、繁简（`zhconv`）、大小写、空格标点都忽略，对中文名、原名和各来源的译名、别名逐个比：

- 完全一致；
- 说出标题中连续的一大段（≥ 3 字且 ≥ 标题 40%，标题 ≥ 5 字时才允许），如「旷野之息」「上低音号」；
- 主副标题之间有分隔符时只说主标题也算，如「荒野大镖客2」；
- 句子里包含完整标题（标题 ≥ 4 字），如「是不是极乐迪斯科」。

## 数据来源

仓库里不带任何图片和题库，全部在运行时从下面这些地方拉取，版权归原作者和各数据源所有：

| 来源 | 用途 | 说明 |
|---|---|---|
| [Bangumi](https://bgm.tv) API | 动画榜单、中文名 | |
| Metacritic | 游戏评分榜 | 网页前端用的非官方接口，key 每次构建从网页源码里现找；改版了可能失效 |
| [IGDB](https://www.igdb.com) / Steam | 游戏截图、热度、别名 | IGDB 需要 Twitch 开发者应用 |
| 哔哩哔哩 | 动画分集封面 | 网页搜索接口，非官方 |
| [AniList](https://anilist.co) | 动画横幅、别名 | |
| [Wikidata](https://www.wikidata.org) | 译名、国家资料 | CC0 |
| [PokeAPI](https://pokeapi.co) | 宝可梦资料和立绘 | |
| [GeoNames](https://www.geonames.org) | 城市坐标、行政区 | CC BY 4.0 |
| [Natural Earth](https://www.naturalearthdata.com) | 国家轮廓 | 公有领域 |
| Google Street View Static API | 街景图片 | 按张计费，遵守 Google Maps Platform 条款 |

## 已知问题

- 截图也可能带字：游戏 UI、标题画面，Steam 截图里偶尔有宣传图；AniList 横幅偶尔带 logo；B 站老番的分集封面只有 480 宽，放大后糊。
- 提示里的人名、公司名会剔除括号内容，并丢掉包含答案的提示，但不保证 100% 不泄露。
- 进行中的题只存在内存里，重启 AstrBot 会丢掉，已扣的额度不退。
